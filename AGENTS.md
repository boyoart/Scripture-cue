# Project: Scripture Cue

## Rules
- Desktop only.
- Windows-first.
- Do not convert this into a mobile app.
- Use Tauri + React + TypeScript + Vite unless blocked.
- Keep modules isolated and testable.
- Prefer clean folder structure over shortcuts.
- Do not skip ahead to advanced features before MVP core is scaffolded.
- For every module, report files created, files changed, how to run, how to test, and known gaps.
